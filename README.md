# ✨ DocuMind AI

An AI-powered document understanding platform that performs OCR, document classification, and AI summarization for PDFs and scanned images.

---

## 🚀 Features

- 📄 OCR Text Extraction using Tesseract OCR
- 🤖 AI-powered Document Classification
- 📝 Transformer-based Text Summarization
- 🔐 User Authentication System
- 📚 Document History Tracking
- 🖼️ Multi-format Support (PDF, PNG, JPG, TIFF)
- ⚡ Interactive Streamlit Web Interface
- 🧠 NLP + Machine Learning Pipeline

---

# 🧠 Tech Stack

| Component | Technology |
|---|---|
| Frontend | Streamlit |
| OCR | Tesseract OCR |
| Classification | XGBoost |
| Feature Extraction | TF-IDF |
| Summarization | Hugging Face Transformers (DistilBART) |
| Database | SQLite |
| PDF Processing | pdf2image |
| ML Serialization | Joblib |
